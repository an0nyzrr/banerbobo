# Collage bot

Telegram-бот: кладёт видео пользователя в верхнюю половину кадра, внизу крутится фиолетовое кольцо.
Посередине видео зависает, поверх него проигрывается баннер с хромакеем (#00FF00), потом видео едет до конца.

## Как работает
1. Присылаешь видео боту.
2. Бот собирает коллаж 9:16 (1080×1920): сверху видео, снизу кольцо (`assets/ring.mp4`).
3. Посередине видео зависает, поверх проигрывается баннер (`assets/banner.mp4`, зелёный фон вырезается хромакеем), потом видео едет до конца.

Баннер фиксированный, его присылать не нужно. Подменить можно через `BANNER_PATH`.

## Запуск
Нужен Python 3.10+. ffmpeg ставить не обязательно: если его нет в системе, подтянется бинарник из пакета `imageio-ffmpeg`.

```bash
pip install -r requirements.txt
export BOT_TOKEN=123456:ABC...        # токен от @BotFather
export CUT_RATIO=0.5                  # где зависает видео (0..1), по умолчанию середина
python bot.py
```

Команда: `/start` — подсказка.

## Файлы
- `collage.py` — сборка через ffmpeg (без Telegram, можно вызывать напрямую)
- `bot.py` — Telegram-обёртка
- `assets/ring.mp4` — фиолетовое кольцо (нижняя половина)
- `assets/banner.mp4` — баннер с зелёным фоном

## Ограничения
- Bot API скачивает файлы до 20 МБ и отправляет до 50 МБ.
- Long polling, отдельный сервер не нужен.
- Чтобы использовать свой ffmpeg, задай `FFMPEG_PATH`.

## Docker

```bash
docker build -t collage-bot .
docker run -d --restart unless-stopped -e BOT_TOKEN=123456:ABC... collage-bot
```

В образе уже есть ffmpeg.
